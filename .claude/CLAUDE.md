# cpp-http-server — Инструкции для Claude Code

> **Актуальные инструкции находятся в `.opencode/OPENCODE.md`** — этот файл является redirect.
> Правила, архитектура, memory — всё в `.opencode/`.

## Быстрый старт

1. Прочитай `.opencode/memory.md` для контекста текущей задачи
2. Прочитай `.opencode/OPENCODE.md` для полных инструкций
3. Правила: `.opencode/rules/*.md`
4. Архитектура: `.opencode/architecture.md` и `.opencode/rules/architecture.md`
